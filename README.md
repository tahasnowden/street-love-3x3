# Street Love 3x3

Site statique pédagogique présentant un tournoi fictif de basket 3x3 inclusif.

## Pages
- `index.html` : présentation de l'étudiant, de la formation et de l'université
- `evenement.html` : concept et engagements du tournoi
- `programme.html` : programme prévisionnel
- `informations.html` : informations pratiques
- `inscription.html` : formulaire HTML de démonstration

## Fichiers
- `style.css` : feuille de style commune à toutes les pages
- `script.js` : gestion du menu mobile et retour local du formulaire
- `images/` : illustrations SVG créées pour le site
- `note-ia.txt` : note explicative sur l'utilisation de l'intelligence artificielle

## Technologies utilisées
HTML, CSS, JavaScript et SVG.

## Tester le site
Ouvrir le fichier `index.html` dans un navigateur pour consulter le site localement.

Pour publier le site avec GitHub Pages, téléverser directement tous les fichiers du projet à la racine d'un dépôt GitHub, puis sélectionner `main` et `/ (root)` dans **Settings > Pages**.

## Important
Cet événement est fictif. Le formulaire est une démonstration : il n'envoie et ne stocke aucune donnée. Les dates, lieux et modalités d'un éventuel événement réel restent à confirmer.
